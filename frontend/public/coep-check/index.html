How to read this. crossOriginIsolated=true means COOP+COEP were both applied to this document. If the tcgdex no-cors probe also loads, the policy is credentialless (or the server sent CORP, which it does not). If the probe fails while crossOriginIsolated=true, the policy in effect is require-corp and card art is being blocked. If crossOriginIsolated=false, the headers never reached this document (or the browser is Firefox/Safari, which do not implement credentialless).

Only images are probed on purpose: the CSP connect-src does not list assets.tcgdex.net, so a fetch() here would be blocked by CSP and say nothing about COEP. Images are also the real case (card art is loaded with a plain <img>).

This page is served by location ^~ /coep-check/, which mirrors the SPA's headers, and the service worker is told never to answer for it, so the result is always this document and not the app shell. Open it at /coep-check/ (with the trailing slash).
